## 0. 一句话目标

对每条询盘，用**本站自有信号**算出一个**确定性**的意向分与分级，后台可见、**可人工覆盖**；**不接外部供应商、不做数据出境、不打 LLM**。

（台账原文：`① 意向评级（无外部供应商、无数据出境）—— 用本站自有信号做规则版评分（询盘内容关键词 / 来源页 / 国家 / 下载行为 / 复访次数），后台给分级且可人工覆盖。这半可以立刻做。`）

## 2. 可用信号清单（逐条：表名 + 列名 + 类型 + 价值）

### 2.1 `inquiries`（[database/008_leads_integrations.sql:1](../database/008_leads_integrations.sql)）

| 列 | 类型 / 约束 | 信号价值 | prod 填充率 |
| --- | --- | --- | --- |

| `status` | text CHECK(`new`/`processing`/`qualified`/`replied`/`closed`/`spam`) | 已有**业务**分级，⚠️ 见 D3 | 0 行 |
| `name` / `company` / `phone` | text | 弱（company 非空算一分） | 0 行 |
| `email` | citext NOT NULL | **关联键**（跨信号 / 复访近似） | 0 行 |
| `country` | text | 中（来自 CF-IPCountry） | 0 行 |
| `locale_id` | uuid → locales | 弱（语言） | 0 行 |
| `message` | text NOT NULL | **强**：长度 + 关键词 | 0 行 |

| `utm_source` / `utm_medium` / `utm_campaign` / `utm_term` / `utm_content` | text | 中（付费 / 自然） | 0 行 |
| `ip_address` | inet | 弱（去重 / 风控） | 0 行 |

### 2.2 `inquiry_items`（同文件:2）—— **最强信号**

`id`, `inquiry_id` → inquiries, `product_id` → products, `product_name_snapshot`, `sku_snapshot`, `quantity numeric(14,3) CHECK(quantity > 0)`, `unit`, `notes`

→ **有明细 = 明确采购意图**；`quantity` 大 / `notes` 非空 = 更强。prod **0 行**。

### 2.3 `download_events`（同文件:3）

`id`, `media_id` → media_assets, `product_id` → products, `email citext`, `country`, `locale_id`, `source_url`, `ip_address`, `created_at`

→ 下载行为；按 `email` 与 `inquiries` 关联（可行性已设计但**无数据可验**，见 §1）。prod **0 行**。

### 2.4 明确不可用（请 L1 不要设计依赖它们的断言）

- **无 page_view / 会话 / 复访计数表** → 「复访次数」只能由「同一 `email` 的 `inquiries` / `download_events` 计数」**近似**
- 无行业库、无第三方 enrich、无历史评分数据

## 3. 硬约束（L1 的断言必须满足）

1. **`pnpm test` 必须继续免库**（现有 29 用例的既定口径）→ **评分核心必须是纯函数**：输入 = 信号聚合对象，输出 = 结果，**不直接查库**
2. **绝不真打外部**（LLM / 反查 API / 网络）
3. 夹具自清；测试**不得依赖 prod**
4. `tests/` 由 L1 产出，**L2 只读**（项目纪律）
5. **已应用迁移 001–028 一律不许改**（`schema_migrations` 有 sha256 校验，改了会中止发布），新增只能 `029+`
6. **确定性**：同一输入必须同输出 —— 禁止 `now()`、随机、时区敏感逻辑进入纯函数

| # | 决策点 | L2 建议（**供裁定，非结论**） |

## 5. 权重草案（**L2 建议，非结论，请 L1 裁定**）

| 信号 | 来源（表.列） | 建议权重 |
| --- | --- | --- |
| 有询价明细 | `inquiry_items.inquiry_id` | **+30**（每条明细另 +5，封顶 +50） |
| 明细 `quantity > 1` | `inquiry_items.quantity` | +10 |
| `message` 长度 ≥ 200 / ≥ 500 | `inquiries.message` | +10 / +20（取一档，不叠加） |
| 采购关键词命中 | `inquiries.message` | +15（MOQ / price / quote / quotation / container / order / FOB / CIF / 采购 / 报价 / 起订量） |
| `inquiry_type` ∈ (rfq, sample) | `inquiries.inquiry_type` | +15 |
| `source_url` 指向产品页 | `inquiries.source_url` | +10（首页 / 联系页 +3） |
| `country` 非空 | `inquiries.country` | +5 |
| 同 email 有下载记录 | `download_events.email` | 每类 +5，封顶 +15 |
| 同 email 历史询盘 ≥ 2（复访近似） | `inquiries.email` 自连接 | +15 |
| `utm_source` 非空（付费渠道） | `inquiries.utm_source` | +5 |
| **分级建议** | 总分 | **≥70 hot / 40–69 warm / 10–39 cold / <10 观察** |
| **垃圾信号** | `message` 含 `<a href` 或 spam 词 | 直接 0 → `cold`（是否标 `spam` 待 L1 定） |
