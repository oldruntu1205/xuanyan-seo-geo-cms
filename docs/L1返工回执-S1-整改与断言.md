## 一、逐条对应（必修 3 条）

### 【必修 1｜P1】隐藏市场块、CTA 后会重新出现 —— 已修

**根因**（L1 判断正确）：`homepage()` 先过滤 `hidden`，再在**过滤后**的集合里判断"是否缺少该块"，于是「显式隐藏」被误判成「未配置」，兜底把块补了回来。

**整改**（`packages/ui/src/index.ts`）：
```diff
- const visible=d.body.filter(b=>!b.data?.hidden);
- const has=(type:string)=>visible.some(b=>b.type===type);      // ← 在可见集合里判断"缺失"
- return body+(has('market_procurement')?'':tradePublicSection(d))+(has('cta')?'':closeBlock(d));
+ const isHidden=(b:Block)=>b?.data?.hidden===true;              // 单一判据：严格 true
+ const configured=d.body;                                      // 「是否配置过」用未过滤集合
+ const visible=configured.filter(b=>!isHidden(b));             // 渲染只用可见集合
+ const body=visible.map(b=>b.type==='product_grid'?homeCollection(d,b):block(b,d)).join('');
+ const ctaConfigured=configured.some(b=>b.type==='cta');
+ return body+(ctaConfigured?'':closeBlock(d));
```
市场块的渲染层兜底**整体删除**（见 Q2）；cta 只保留**有边界**的兼容兜底：**完全没有配置任何 cta 块**时才补默认结尾。
