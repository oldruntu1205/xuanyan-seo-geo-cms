# 运营使用说明

## 1. 初始化

1. 打开 `/admin`，创建首个管理员。随后进入 `/manage`。
2. 系统 → 站点配置：填写公司名称、公开域名、邮箱、电话、默认语言。
3. 系统 → 站点翻译：选择站点和语言，填写各语言公司介绍、页脚和版权。
4. 默认九种语言均启用；不准备发布的语言可关闭。语言代码创建后不可重命名。

## 2. 页面、文章、案例、应用、解决方案

1. 内容 → 页面 / 文章：新建主记录，选择 `page/article/guide/case_study/application/solution/landing_page`。
2. 内容翻译：关联主记录和语言，填写标题、slug、完整路径（如 `/en/about`）。
3. 在正文区块编辑器添加正文、图文、列表、FAQ、参数表、视频、CTA、询盘等模块；支持上下移动与删除。
4. 也可在「页面区块」维护排序区块。有启用的独立区块时，其内容优先于翻译记录的正文区块。
5. 图片先上传至媒体库；区块填写公开图片地址 `/media/<object_key>`，对象存储使用公开域名地址。
6. 保存草稿后由管理员或审核员点击发布。队列中显示 completed 才表示任务完成。

分类、FAQ、案例和应用使用相同语言关联方式。FAQ 主记录须设为 published，才会进入关联页面的发布快照。

## 3. 产品

1. 产品：新建唯一 SKU，填写品牌、型号、材料、尺寸等共享信息。
2. 产品翻译：分别创建名称、说明、语言路径。
3. 规格定义 → 规格名称翻译 → 产品规格值：为产品设置文本、数值或布尔规格；每行只能有一种值。
4. 产品图库：关联已上传媒体，选择角色与排序。
5. 产品资料：关联 PDF 等下载资源。相关产品通过「关联产品」配置。
6. 发布产品翻译；页面包含参数、图库、资料下载和 RFQ 表单。

## 4. SEO / GEO

先创建 SEO 元数据、GEO 知识实体或 JSON-LD 记录，再将其编号关联到内容/产品翻译。

- SEO：标题、摘要、canonical、索引规则、OG 图片。
- GEO：简洁回答、定义、关键事实和可追溯来源。系统不会自动编造事实。
- JSON-LD：不填写时自动输出组织、网页/文章/产品、面包屑与 FAQ；可用自定义 schema_json 覆盖。
- 路径采用 `/语言/小写路径`。内容、产品、分类共享路径唯一约束；禁止目录穿越及跳转循环。
- 已发布页面改路径后自动建立旧地址 301；新页面发布完成前旧静态页面仍可能存在。
- 搜索只读已发布内容。FTS 使用 PostgreSQL simple 分词，中文按原样检索能力受其分词方式限制。

## 5. 首页、菜单、客服

- 首页轮播：配置桌面/移动图片、时长、文字位置、遮罩、展示时间，随后添加轮播翻译。
- Hero 支持自动切换、暂停、键盘和触摸；首屏图片优先加载。
- 菜单按父级和排序呈现；链接可自定义或关联内容/产品/分类。
- 客服支持 WhatsApp、邮件、电话以及微信/LINE/Messenger 的配置链接；根据语言、国家和工作时间选择渠道。国家默认使用可信代理传入的 CF-IPCountry，没有国家信息时使用全球规则；客服 API 也接受 country 参数。工作时间格式为 `{"timezone":"Asia/Shanghai","days":{"1":[["09:00","18:00"]]},"offlineText":"请留言"}`，0 为周日，1 为周一；不设置时全天可用。
- 修改全局外观后点击「重建已发布站点」。它重新计算输出，内容不变的 HTML 文件不会重写。

## 6. 询盘和权限

访客提交联系或 RFQ 表单后，后台「询盘 / RFQ」可查看、分配、更新处理状态。重复提交同一 key 只产生一条询盘；来源限制、频率限制和隐藏反垃圾字段已接入。

账号与密码在 `/admin` 管理。业务角色在 Payload 账号上选择，业务权限由角色权限表定义；用户角色表可以额外赋予业务角色。

| 角色 | 默认能力 |
|---|---|
| super_admin / admin | 全部业务管理与账号管理 |
| editor | 内容、产品、媒体、外观编辑 |
| seo_manager | SEO/GEO 编辑 |
| translator | 翻译记录与翻译工作流 |
| reviewer | 发布、定时、取消、重试、版本查阅 |

编辑人员不能通过提交 published 字段绕过发布权限。公开页面始终读取发布快照。版本恢复先恢复为草稿，需要重新审核发布。

## 7. 统计与邮件

站点配置填写 GA4 Measurement ID 后，访客允许统计才加载 GA4。`settings_json.google_site_verification` 可配置 Search Console 验证标记。

SMTP 环境变量用于账号密码重置邮件。未配置 SMTP 时 Payload 的开发邮件仅输出到服务日志；生产请配置实际邮箱服务。

## 8. 发布语义

定时发布保存提交时的内容快照，之后编辑草稿不会改变该快照。路径在定时任务执行前变更会使任务失败，应重新提交。发布采用每个文件的原子替换；多页更新期间可能短暂看到前后两批页面，不是全站原子切换。

BullMQ 负责重试和调度，PostgreSQL 保留任务事实记录。失败时在发布日志查看原因，修复配置/内容后重试。AI chat 返回 501，表示 V1.0 接口保留，访客可继续使用联系表单。
