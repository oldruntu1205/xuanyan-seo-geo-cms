# 浅色玻璃品牌前台 · 2026-09-26

本轮视觉方向由用户选择：浅色、精致排版、突出产品质感。此版本接续 `FRONTEND-RESKIN.md` 中的藏青金色版本。

## 实施

- 暖白、墨绿、鼠尾草色；衬线标题、细线条、低饱和背景。
- 首页双栏首屏：有已发布产品图片时展示首个产品，附实际产品详情链接；其余轮播使用后台场景图。无产品素材时保留场景图或文字首屏。
- 产品图片采用固定容器比例和 contain，修复图片原始 height 属性导致长条卡片的问题。
- 产品、文章、服务区块采用不同布局，保留 CMS 数据驱动。
- 同步调整详情页、询盘、FAQ、页脚及移动端布局。
- 共享渲染器及 CSS 同时服务 Next 预览和后续静态发布。

## 文件

- `packages/ui/src/index.ts`：首屏与区块结构。
- `packages/ui/src/premium.ts`：集中管理本轮主题覆盖，避免丢失既有组件样式。
- `packages/ui/src/styles.ts`：组合基础组件样式和主题。
- `tests/render.test.ts`：保留原测试，补充产品首屏及轮播回归。
