# V3.1 外贸获客体验升级

状态：本地代码已落盘，数据库迁移与浏览器业务验收待执行。基线为 V3.0 已落盘的多语言、产品、询盘、CRM 和静态发布能力；生产同步由站点所有者负责。

## 目标与边界

让海外采购商从企业首页了解供应能力，查看可核实的产品资料，将多个产品放入同一 RFQ，并让销售在现有询盘工作台看到完整需求。首页只展示 CMS 已发布或管理员提供的事实与素材，不制造产能、证书、价格或客户评价。

本轮的最小代码边界是：静态发布器与共用前台渲染、产品共享/语言字段、询盘 API 与后台展示。沿用 `published_documents` 快照、`products` / `product_translations`、`inquiries` / `inquiry_items`，不引入第二套内容或销售数据源。原有单产品询盘继续可用。

## V3.1 实施顺序

| 阶段 | 交付 | 验收口径 |
| --- | --- | --- |
| 1 首页 | 从已发布产品、案例、内容与站点/轮播资料构成采购导向首页；支持桌面和手机 | 首页内容可通过 CMS 编辑并在全站重建后更新；空内容不展示虚构证明；入口可抵达产品与询价 |
| 2 产品资料 | MOQ、交期与多语言包装、定制、样品政策；沿用规格、图库、资料下载 | 管理员能编辑；产品重新发布后访客看到对应语言资料；空字段不展示 |
| 3 多产品 RFQ | 产品加入询价单、数量调整、目标市场、需求日期、贸易条款、需求备注及受控文件附件 | 一次提交保留每项产品快照；服务端重新核验已发布产品；重复提交幂等；后台可读需求和附件 |

## 技术与安全口径

- 数据库迁移 `022_trade_conversion.sql` 增补字段与受限附件表，配回滚脚本；先备份再迁移。
- 产品图片、资料、证书继续使用现有媒体体系。证书只显示人工上传的文件，不自动声称认证有效。
- RFQ 文件只接受 PDF/JPEG/PNG/WebP，最大 5 MB，私有存储于数据库并由有询盘读取权限的用户下载；不把附件放入公开媒体库或静态快照。长远可迁入私有对象存储。
- 浏览器询价单保存在本机，服务端忽略浏览器提供的产品名称和价格，仅通过已发布产品查询建立快照。数量、字段长度、类型、文件签名和请求体大小均在服务端约束。
- 不新增自动对外发送；沿用现有隐私处理同意与询盘频控。营销订阅继续独立。
