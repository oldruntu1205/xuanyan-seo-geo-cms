## 实施范围

1. 获客漏斗：自愿统计的访问会话；按询盘创建日期分组，追溯有效询盘、已发报价、成交商机，支持来源、语言、国家、产品筛选。
2. 报价协作：从多产品 RFQ 建立报价，币种、单价、数量、贸易条款、有效期；不可覆盖的版本、独立审核、客户确认、CRM 时间线。

4. 采购信任与服务：证书、案例、服务承诺及有效期；实时排除失效证明；分市场响应时限与首响记录。
5. 客户与渠道入口：针对单份询盘生成限时邀请；客户可查看公开报价并确认，渠道仅查看；可撤销，令牌哈希保存，不自动发送消息。

## 使用入口

后台 `/manage` → **外贸业务**，包含五个功能标签。后台列表使用客户名、产品名、页面标题及语言名，不要求操作人员输入 UUID。

### 报价与邀请

1. “报价协作”中选择带有产品清单的 RFQ，填写数量、单价、币种、贸易条款、有效期和说明；可选择关联该询盘已有商机。
2. 保存独立版本并提交审核。另一位同时拥有客户写入和发布审核权限的同事审核通过。管理员也不能审核自己编制的报价。
3. 点击“发出到客户入口”，向持有有效邀请的客户展示。此操作不发送邮件。
4. 在“客户与渠道入口”生成 1–30 天邀请；客户邀请必须匹配询盘邮箱，渠道邀请仅有只读权限。人工核对接收人后复制发送。
5. 链接仅限单份询盘。64 字符随机令牌仅显示一次，数据库只保存 SHA-256 哈希；令牌位于 URL fragment，页面读取后立即移除，不写入浏览器持久存储。撤销即时生效。
6. 客户可确认或拒绝最新、已发出且仍在有效期内的报价。报价内容无法覆盖；客户决策不会自动把 CRM 商机标记为赢单，也不等同于付款或电子签约。
7. 每行金额由 PostgreSQL decimal 四舍五入至两位小数再合计，前台直接显示该行金额快照。未自动计算税费、运费或汇率，编制人须在报价说明中明确。

普通联系询盘没有产品明细时，先向客户确认 RFQ 产品清单。本轮不提供任意手工商品或服务行报价。客户门户为中英双语，具备打印/保存 PDF 功能。

### 市场内容与信任

- 市场推荐、案例关联同语言已发布页面；证书、服务承诺也可关联公开 HTTPS 证明地址。来源链接将公开。
- 卡片保存后待审核，由另一位有内容写入和发布审核权限的同事发布。修改采用新建版本、重新审核和撤下旧卡片。
- 国家使用 ISO 两位代码，留空为通用；官网可切换采购目的地，展示当地及通用内容。
- 证书必须有有效期。公开 API 每次读取时检查日期、审核状态和关联页面快照哈希；失效、撤下或来源变更的内容不返回。已有打开的页面需刷新后反映变化。
- 官网首次接入组件需要更新站点资产并重建静态站点；此后卡片审核/撤下无需重建。推荐卡片通过浏览器加载，SEO 的正式内容仍以来源页面为准。

### 服务时限与统计

- 设置语言/国家首次响应时限，以自然小时计算；指定国家规则优先于语言默认。规则写入后只影响新询盘，历史时限保留。
- 记录实际人工回复的渠道与内容，系统记录当前时间为首响登记时间。不会自动代发回复或提供非工作时间排班。
- 官网国家输入改为地区下拉框，统一储存两位代码；旧询盘的自由文本国家未自动改写。
- 漏斗按询盘创建日期（UTC）筛选，后续阶段统计至生成时刻；有效/报价/赢单可独立发生，不能当成严格逐级递减序列。有效阶段依据当前状态及 CRM 历史，赢单依据当前商机状态。
- 只统计明确同意的会话，不推算全量访客或归因因果；国家/产品筛选下不展示会话总量。会话到询盘的关联通过访客自愿统计令牌实现，未关联询盘仍计入询盘总量。
- 同意文案明确说明来源关联，使用新偏好键 `suns_analytics_v2`，已有匿名分析同意不会直接沿用。访客可在页脚重新设置偏好；拒绝后停止采集并清理本次会话标识。
- 漏斗单次最多 10,000 份询盘，超出须缩小日期或筛选条件。公开统计未实现自动数据保留清理；应按实际站点隐私政策制定数据库保留周期。

## 升级与回退

1. 备份目标环境数据库；确认运行库地址，不要把 `.runtime/connection.json` 的本地演示连接复制到生产。
2. 使用目标库环境变量执行 `pnpm db:migrate`，依次应用所有缺少的迁移。
3. 更新 CMS、Web、Worker 代码和静态资产；重建站点，以更新首页模块、国家选择、统计偏好和门户链接。
4. 使用不同编辑/审核账号完成报价、卡片审核，再用客户和渠道邀请分别验收查看/确认权限。
5. 首响规则与证书等真实业务资料需由运营填写；本轮没有预置虚构证明或承诺。

需要回退时先停写、备份新增业务数据，然后使用旧代码并回滚 023。回滚会删除所有本轮报价、邀请、市场卡片、规则和会话数据，不能用于日常“撤销报价”。备份副本仅在本地实例内，应另行执行常规外部备份策略。
