# 《SEO/GEO 多语言静态 CMS V1.0 系统架构》

## 1. 项目定位

这套系统不是普通企业官网 CMS，而是：

> **面向 Google SEO、AI 搜索 GEO、多语言海外获客、静态化高性能发布的企业级内容管理平台。**

主要目标有四个：

- **搜索友好**：Google 可抓取、可索引、结构清晰
- **AI 搜索友好**：内容结构适合 AI 搜索和答案引擎理解
- **发布高性能**：内容发布后自动生成静态 HTML
- **运营可管理**：营销人员无需改代码即可维护页面、产品、文章、SEO、语言和客服配置

# 8. Static Publish Engine

这是本项目的核心。

正式确定：

> **前台生产环境优先提供真实静态 HTML。**

不是普通 SPA。

也不是每次请求 SSR。

架构：

```text
CMS Publish
      ↓
Publish Hook
      ↓
BullMQ Job
      ↓
Static Worker
      ↓
Render Route
      ↓
Write HTML
      ↓
Update Sitemap
      ↓
Purge CDN
```

# 9. 增量静态生成

不能每次发布都重建整个网站。

例如发布：

```text
/en/blog/article-a
```

系统计算：

```text
Affected Routes
```

生成：

```text
/en/blog/article-a/

/en/blog/

/en/

/en/category/laboratory-glassware/

/sitemap-blog-en.xml
```

而不是重建：

```text
200,000 pages
```

这个机制正式命名为：

> **Incremental Static Publishing — ISP**

避免和 Next.js ISR 混淆。

```text
Google / AI Crawler 抓取
```

这就是整个 V1.0 的核心运行逻辑。

**《SEO/GEO 多语言静态 CMS V1.0》正式采用：**
